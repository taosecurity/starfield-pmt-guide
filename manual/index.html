Summary

Part 1 shows how to run the PMT tools yourself from a command prompt and read what they report. It has pages for players who manage a load order and for modders who build and release mods. Every page has a twin in Part 2 for people who want an agent to run the commands.

On this page
  • For players
  • For modders
  • The appendix

Part 1 is for people who type the commands and read the reports themselves. You decide what to install, what to change and what to share. The tools only read and report, except the builders, which write your own mod's files. PMT runs on a PC; console players can check a mod on a PC, and modders build console versions there.

If you have not installed anything yet, start with Getting started. If you would rather have an agent run the commands while you decide, see Part 2.
