Using Richard's Public Modding Tools

By Richard Bejtlich, Richard Presents Starfield Essentials on YouTube

More Starfield tools and references are on the Richard Presents Development Hub.

Summary

This guide teaches Richard's Public Modding Tools (PMT) by task, for Starfield players and modders on PC. Every task has two mirrored pages, one for running the tools yourself and one for having an AI agent run them while you decide. The tools are free, they run on a Windows PC, and the decisions always stay yours.

PMT supports manual modding and Human Developed, Agent Programmed modding.

PMT (Richard's Public Modding Tools) is a set of free, open-source tools for Starfield on PC. They check load orders, mods, saves and logs, and they build mods. You can run them yourself (Part 1), or have an AI agent run them while you decide (Part 2). PMT runs on a Windows PC, and some tools also run on Linux. No tool runs on a console, so console players can check a mod only on a PC, and modders build their console versions there.

Who the guide is for

Players on PC. You play on Steam or Game Pass, and you install mods with Vortex, Mod Organizer 2 (MO2), no manager at all, or only the in-game Creations menu. PMT helps you check your load order, look at a mod before you install it, find mods that change the same records, check a save and send a good bug report.

Creation Kit and xEdit authors. You make plugins by hand in the Creation Kit (CK) or xEdit. PMT doesn't replace either one. It checks, tests and helps you release what you made.

Code builders. You write plugins in C# with BuildKit and Mutagen, and you build the whole mod with sf-mod-build. PMT covers the build, the checks, the tests and the release.

Tools

PMT has 15 tools. You only need the ones for the jobs you want to do. Getting started shows how to install each one and check its download.

ToolWhat it doesWho uses it
sf-load-orderChecks a load order and says in plain words what is wrong and how to fix it, and can sort a load order from your rules and suggest an order, without changing anything itself.Both
sf-mod-checkReads plugins and zips and reports broken plugins, changes lost between mods, files a release lacks and what a download contains.Both
sf-save-healthChecks a save against the mods installed now and reports missing plugins, leftover data, broken quests and bloat.Both
sf-save-readerShows what is in a save: the character, the game version, the plugins it depends on and the state of every quest.Both
sf-log-collectorGathers your logs, INI files, load order, crash logs and (if you ask) saves into one zip for a bug report.Both
papyrus-log-checkReads the Papyrus log after a test and marks each rule PASS, FAIL or NOT SEEN, and explains common script errors.Both
sf-patch-daySays after a game update which SFSE plugins still load, and whether the update changed what your mod relies on.Both
StarfieldVoiceToolA desktop app that lists, plays and exports the game's voiced lines and sounds, with a command-line exporter.Both
sf-mod-buildBuilds a whole mod from one project file: scripts, plugin, archives and a zip that mod managers install as is.Modders
BuildKitA C# library for programs that write Starfield plugins with Mutagen the way the Creation Kit does.Modders
sf-test-planTurns a plain-text test plan into an offline checklist page that a tester ticks off while playing.Modders
sf-papyrus-refAnswers offline whether a Papyrus function exists, on which script, and whether it works on Xbox, and checks a mod's scripts.Modders
sf-pex-toolsTells you whether two compiled scripts do the same thing, and lists, extracts and compares files in BA2 archives.Modders
sf-cut-checkReports records the player can never meet, in the game or in your own plugin, with the chain that explains each one.Both
starfield-agentA Claude Code plugin that teaches an AI agent to use these tools carefully, with skills, guards and a Papyrus lookup server.Both

Every tool reads your files and writes only its own reports and outputs, except the builders, which also write your own mod's files. No tool edits another author's plugin, your saves or your load order, and no tool uploads anything.

Manual or AI-assisted

Both halves teach the same tasks with the same tools and the same commands. The difference is who types the commands and who reads the reports first.

Manual (Part 1)AI-assisted (Part 2)
SetupInstall each tool you need from its GitHub release and check its checksum.The same tools, plus an AI coding agent. Claude Code can add the starfield-agent plugin, and other agents read each tool's AGENTS.md.
CostFree. Every PMT tool and every other tool named in this guide is free.The tools are free, but the agent is usually a paid service.
SpeedYou type each command and read each report. It is fast once you know the tools.The agent chains the commands and summarizes the reports. It is faster for long jobs, and slower when you must check its work.
Skill neededComfort with a command prompt and with reading reports.Comfort describing what you want and checking what the agent did. Knowing the tools still helps.
Who runs the toolsYou.The agent, on your PC, with your permission.
Who reads the reportsYou.The agent reads them first and explains them. You read the parts that matter.
Who decidesYou.You. The agent suggests, and installing, applying a load order, permission and uploading stay yours.
How errors are caughtThe tools' own checks, exit codes and RESULT: lines.The same checks, plus starfield-agent's guards (they refuse changes to the game folder and committing game code), plus your review of the agent's claims against the reports.
PrivacyThe tools make no network calls. Logs and reports can hold folder names, so read them before you post them.The same, but the agent's service sees what the agent reads, including file names and log text. Don't let it read what you wouldn't share.

Benefits and shortcomings

Manual

  • Benefits. It costs nothing, and nothing leaves your PC. You learn what each check means, so you can judge a report yourself. It works for any player with a PC and a command prompt.
  • Shortcomings. It takes more typing. Long jobs, such as a release check or a full test round, take many steps, and it is easy to skip one.

AI-assisted

  • Benefits. You can ask in plain words. The agent chains the steps and drafts the results for you. The starfield-agent skills follow a careful order: they ask about permission first, they never compile scripts in release mode, and they leave every upload to you.
  • Shortcomings. It usually costs money. The agent can misread a report or invent a Papyrus function name (sf-papyrus-ref helps it check names). Its service sees what it reads. You still need to check its claims against the tools' own output.

Where to start

  • New to modding tools: start with Getting started, then Check and improve a load order in Part 1.
  • Comfortable with a command prompt and an agent: read Getting started, then Set up an AI agent, then the Part 2 page for your task.
  • Modders: Test and debug a mod and Release a mod are useful even if you never build with code.
  • Wondering how PMT fits with the tools you already use: read How PMT compares with other tools.
Note

PMT is free, and so are Vortex, MO2, LOOT and xEdit. An AI agent usually is not. If you don't want to pay for one, Part 1 covers every task by hand.
