Part 2: AI-assisted

Part 2: AI-assisted (Human Developed, Agent Programmed)

By Richard Bejtlich, Richard Presents Starfield Essentials on YouTube

More Starfield tools and references are on the Richard Presents Development Hub.

Summary

Part 2 shows how to have an AI agent run the PMT tools while you make the decisions. Each page mirrors a Part 1 page and says what to ask, what the agent runs, what you check and what stays your decision. The tools are free, but the agent is usually a paid service.

On this page
  • Set up
  • For players
  • For modders
  • The appendix

Part 2 is for Human Developed, Agent Programmed modding. You describe what you want in plain words. The agent runs the same commands as Part 1, reads the reports first and explains them. You check its claims against each tool's own report, and you keep every decision about installing, applying a load order, permission, uploading and sharing.

The agent's service sees what the agent reads, including file names and log text. Read Guardrails for AI use before your first session. PMT runs on a PC; console players can check a mod on a PC, and modders build console versions there.

Start with Set up an AI agent. If you want to run the commands yourself, see Part 1.
