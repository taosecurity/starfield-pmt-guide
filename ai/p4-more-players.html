Part 2: For players

Saves, bug reports and patch day with an agent

Do this by hand

By Richard Bejtlich, Richard Presents Starfield Essentials on YouTube

More Starfield tools and references are on the Richard Presents Development Hub.

Summary

Your agent checks a save, reads the logs from a test session, and tells you which of your Starfield Script Extender plugins still load after an update. It adds the redact option to anything you plan to share and never calls a save safe because a tool exited 0. You play the game, make the saves and decide what to post.

On this page
  • What to ask
  • What the agent runs
  • What you check
  • What stays your decision

What to ask

Ask your agent
Check my newest save against my installed mods and tell me what the report says was and was not checked. Redact the output, because I want to share it.
Ask your agent
I just removed a mod. Compare the save I made before with the one I made after, and tell me what changed.
Ask your agent
I had a crash. Read the log zip I just collected, explain the errors in plain words, and tell me what is safe to post.
Ask your agent
The game updated. Check which of my Starfield Script Extender plugins still work.

What the agent runs

Two starfield-agent skills cover this page. patch-day handles the update check, and log-review reads logs after a test and drafts what they show. For saves and logs the agent follows each tool's AGENTS.md, and other agents follow the same files. The commands match the manual page.

Checking a save:

Command Prompt
sf-save-health check "<save.sfs>" --plugins "%LOCALAPPDATA%\Starfield\Plugins.txt" --redact
Command Prompt
sf-save-health solo --before "<before.sfs>" --after "<after.sfs>" --redact
Command Prompt
sf-save-reader quests "<save.sfs>" --data --details --redact

Collecting and reading logs. You run the collector yourself, after you quit the game:

PowerShell
powershell -ExecutionPolicy Bypass -File .\Collect-StarfieldTestLogs.ps1 -Note "short description"

To share the zip, add -Redact. It hides your Windows user name, computer name, user folder and Steam account number in the copied text files, but not in saves, screenshots or file names.

PowerShell
powershell -ExecutionPolicy Bypass -File .\Collect-StarfieldTestLogs.ps1 -Note "short description" -Redact
Command Prompt
python -I papyrus_log_check.py "<StarfieldLogs zip>" --rules rules\papyrus-runtime-errors.logrules.json --rules rules\papyrus-scripts-and-properties.logrules.json --rules rules\papyrus-saves-and-load.logrules.json

Patch day:

Command Prompt
.\sf-patch-day.cmd dlls

Looking up voice lines:

Command Prompt
starfieldvt-export voices --out voice-out --search "captain" --list

What you check

  • Never trust exit 0 alone. The agent must not call a save safe from exit 0. It should quote the last lines of the report, which say what was not checked.
  • Exit 2 from sf-save-health. It means problems were found. It is normal after you remove a mod. Only exit 3 means the check did not run.
  • Heuristic rules. The agent should say so when it reports quest-state or save-bloat findings, because they can raise false alarms.
  • Log results. Check each PASS, FAIL or NOT SEEN in the papyrus-log-check report yourself. NOT SEEN usually means the feature was not tested.
  • Patch day verdicts. WORKS is not a promise. MAY FAIL needs a test in the game. dlls exits 0 when every DLL works and 1 when some need Address Library, may fail or need a newer SFSE, so exit 1 is a normal result to read, not a failure of the tool. For each SFSE plugin it also prints a framework line that says whether the plugin was built on CommonLibSF (a large C++ library for Starfield plugins), on plain SFSE, or "can't tell", with the evidence that decided it. It reads the DLL's bytes and never loads or runs the DLL, and the verdicts and exit codes are the same as before (sf-patch-day 0.3.0). On Game Pass the command exits 2 because SFSE doesn't support Game Pass, and exit 3 means it could not read.
  • Redaction. Confirm --redact was on for anything you plan to share. Without it, a --log file holds full paths.
  • solo needs two hard saves. It refuses an exit save, the same save twice, two different characters, or an "after" save older than the "before" save (exit 3). Make one manual save before the change and one after.
  • The zip. Open the collector zip and look inside before you post it, even with -Redact. It leaves saves, screenshots and file names as they are, and a text file it can't redact is left out with a warning.

What stays your decision

  • Playing the game, making the before and after saves, and quitting the game before the collector runs.
  • Keeping backups of your saves. The tools never repair, move or edit a save.
  • Exporting Game Pass saves first with a third-party tool.
  • Whether to share a log, a report or a zip, and with whom.
  • Whether to keep a mod, based on what the reports show.

Read the guardrails before you let an agent act on your files.
