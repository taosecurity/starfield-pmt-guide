Appendix

Glossary

By Richard Bejtlich, Richard Presents Starfield Essentials on YouTube

More Starfield tools and references are on the Richard Presents Development Hub.

Summary

This page explains the terms the guide uses, in plain words and in alphabetical order. Each term has its own heading, so other pages can link straight to it.

On this page
  • Terms

Terms

Add-on

A plugin that uses another author's plugin as a master and adds new records instead of changing the original's. You need the original author's permission first.

Address Library

A free SFSE-related library that lets script extender plugins find the game's functions after a game update. The patch-day checks look at SFSE plugins that depend on it.

Agent

An AI program that can run commands on your PC, read the results and decide on the next step. In this guide, an agent runs PMT tools while you make the decisions.

AGENTS.md

A plain-text file in each PMT tool's repository that tells an agent how to install, run and read that tool, and what it must not do.

Alias

A named slot in a quest that points at a reference, such as the player or a character. Scripts and conditions use aliases by number or name.

BA2

Bethesda's archive format. A mod packs its scripts, meshes and sounds into BA2 files.

BlueprintShips files

Official plugins whose names start with BlueprintShips-. They hold the game's ship designs. A mod's ship change can't override them, and your own plugin must never use a name that starts this way.

Conflict (record)

Two or more mods change the same record. The one that loads later wins, and the changes from the other are lost unless a patch combines them.

Conflict patch

A plugin that picks the winning changes from conflicting mods. PMT builds one for your own game only. It holds other authors' data, so never publish it.

Creation

One item from Bethesda's mod service, Creations. A Creation is an ordinary plugin once the game installs it.

Creation Kit

Bethesda's free editor for making plugins, available on Steam. It is also how you upload to Creations. You'll often see it shortened to CK after its first use on a page.

Creations menu

The in-game screen where you install, remove and order Creations.

Data folder

The game's Data folder, where plugins, archives and loose files go. On Steam it is inside the game's install folder. On Game Pass it is under <drive>:\XboxGames\Starfield\Content\Data.

Debug.Trace

A Papyrus call that writes a line to the Papyrus log. The guide's mods use it with a prefix so you can find their lines.

Editor ID

A readable name for a record, such as the name of an item. Unlike a FormID, a mod can change it, and it is not always unique.

ESM

A master plugin file (.esm). Other plugins can use it as a master, and it loads before ordinary plugins.

Exit code

A number a program returns when it finishes. In these tools, 0 usually means no problem found, and other numbers mean problems or that the check didn't run. Each tool's page says what its codes mean.

FormID

The number that identifies a record. Its first digits say which plugin the record belongs to, so they change when the load order changes.

Game Pass

Microsoft's subscription service. Starfield from Game Pass runs through the Xbox app on PC.

Gap check

A check (sf-mod-check gap) that finds data the Mutagen library would lose when it writes a plugin. BuildKit's own check runs the same test.

Human Developed, Agent Programmed

The way of working in Part 2: a person decides, checks and approves, and an agent runs the tools and writes the code.

ITM

An "identical to master" record. It is a record in a plugin that copies the original without changing anything. ITMs can hide other mods' changes and are cleaned out in xEdit.

Light, medium and full plugins

Three plugin sizes. Full plugins take a whole slot in the load order. Light plugins share one slot, and medium plugins are an in-between kind that shares another. Light and medium plugins have different FormID rules.

Load order

The order in which the game loads your plugins. When two plugins change the same record, the later one wins.

LOOT masterlist

A community list of rules for sorting plugins. LOOT uses it, together with your own rules, to sort a load order, and sf-load-order sort uses its after rules when it finds the file.

Master

A plugin that another plugin depends on. The game must load the master first.

MCP server

A small program that gives an agent a set of lookup tools through the Model Context Protocol. sf-papyrus-ref has one that lets an agent look up Papyrus names instead of guessing.

Mod manager

A program such as Vortex or Mod Organizer 2 that installs, removes and orders mods.

Mutagen

A .NET library for reading and writing Bethesda plugins. BuildKit is built on it.

Objective

A line of text in a quest that tells the player what to do next, such as "Read the courier's note."

Papyrus

The scripting language the game uses.

Papyrus log

A text file the game writes when Papyrus logging is on. It records script messages and errors, including lines your mod writes with Debug.Trace.

PEX

A compiled Papyrus script (.pex). The game runs .pex files, not source.

Plugins.txt

The file the game reads at startup to learn which plugins are active and in what order. The game also rewrites it. See Load Order Facts.

Quest stage

A numbered step in a quest. Scripts move the quest from one stage to the next.

RESULT line

The line that many PMT tools print at the end, starting with RESULT:. It gives the overall outcome, so it is the first thing to check, along with the exit code.

Rule file

A file of rules for papyrus-log-check. Each rule says what a log should show during a test, and the tool marks it PASS, FAIL or NOT SEEN.

Save version

A number inside a save file that says which game version wrote it. The PMT save tools read only version 153, from Starfield 1.16.244.

SFSE

The Starfield Script Extender, which adds features for mods on Steam on PC. Its plugins are DLL files. It doesn't support Game Pass.

Skill (agent)

A packaged set of instructions that tells an agent how to do one kind of task. starfield-agent has twelve of them.

Spriggit

A tool that turns plugins into text files for Git and back. See Other free tools.

Test plan

A list of steps to follow while you play to check that a mod works. sf-test-plan turns one into a checklist page.

Triage

A quick look inside a download (sf-mod-check triage) before you install it. It lists things to look at, but it never says a mod is safe or unsafe.

Vortex

A mod manager from Nexus Mods. See Other free tools.

xEdit

A free plugin editor. Its Starfield mode is called SF1Edit. It shows conflicts and lets you edit and clean plugins by hand. Since version 4.1.5q, SF1Edit can also save .esp, light and medium plugins, but it can't set or clear the light or medium flag. It ships xDump.exe, a command-line reader that an agent can run.
