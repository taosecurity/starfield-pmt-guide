Appendix

Other free tools

By Richard Bejtlich, Richard Presents Starfield Essentials on YouTube

More Starfield tools and references are on the Richard Presents Development Hub.

Summary

This page lists free tools by other people that PMT works alongside, with what each is for, its license and a link to its official page. Versions are the latest ones seen on 2026-11-24. PMT does not replace these tools, and its guide does not repeat their manuals.

On this page
  • Libraries and command-line tools for builders
  • Plugin editing and load order
  • Mod managers
  • Bethesda's tools
  • Where PMT fits

All of these are free to download. Versions and licenses were read from each project's own GitHub page on 2026-11-24.

Libraries and command-line tools for builders

ToolWhat it is forLicenseVersion seenOfficial page
MutagenA .NET library that reads and writes Bethesda plugins. BuildKit is built on it.GPL-3.00.54.4 (2026-08-08)github.com/Mutagen-Modding/Mutagen
SpriggitTurns plugin files into a text format that works well with Git, and back again.GPL-3.00.41.0 (2026-07-02)github.com/Mutagen-Modding/Spriggit
ChampollionTurns compiled Papyrus scripts (.pex) back into readable source. It supports Skyrim, Fallout 4 and Starfield.LGPL-3.0v1.3.2 (2023-10-03)github.com/Orvid/Champollion
papyrus-tools (Kiyozz)A Papyrus language toolchain with a Visual Studio Code extension.Apache-2.0v0.16.3 (2026-11-03)github.com/Kiyozz/papyrus-tools
DMMDepsLists the files a plugin uses. It is part of ZeeOgre's Dev Mod Manager, and sf-mod-check release --dmmdeps <exe> can run it as an extra check.GPL-3.0dmmdeps v0.4.1 (2026-07-26)github.com/ZeeOgre/DevModManager

Use Champollion only on scripts you have the right to read, such as your own or a mod author's who allows it. Never share decompiled game scripts. See Guardrails for AI use.

Bethesda's tools

PapyrusCompilerCompiles Papyrus source into .pex scripts. It comes with the Creation Kit.Bethesda's own termsInstalled with the Creation Kit, in Tools\Papyrus Compiler under the game folder. There is no separate download.

Note

sf-mod-build uses PapyrusCompiler and Archive2 from your own Creation Kit install. Don't copy them, or the game's scripts, into anything you share.

Where PMT fits

  • Use LOOT to sort, then sf-load-order to check the result.
  • Use Vortex or MO2 to install and remove mods, then PMT to check them.
  • Use xEdit or the Creation Kit to fix records that a PMT report points at.
  • Use Mutagen through BuildKit when you write a mod in C#.
